## 🚀 About

**IPTV Checker** is a PyQt5 desktop application for inspecting and organizing M3U/IPTV playlists. It can load playlist URLs, browse discovered channels, filter them by name, save playlist data and launch selected streams in VLC Media Player.

The repository includes separate **English** and **Polish** script variants.

It is designed for users searching for an **M3U playlist checker**, **IPTV playlist viewer**, **PyQt5 IPTV tool**, **VLC M3U launcher** or a desktop utility for managing lawful streaming playlists.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔗 Multiple URLs | Enter and process multiple playlist addresses |
| ⚡ Async networking | Uses `aiohttp` for responsive network operations |
| 🔎 Channel filter | Search channels by partial name |
| 📂 Playlist browsing | Group and browse discovered entries |
| 💾 Playlist save | Save playlist data locally |
| ▶️ VLC integration | Open selected streams in VLC |
| 📍 Custom VLC path | Select VLC executable manually |
| 🌍 EN / PL | Separate English and Polish application versions |

## 📦 Installation

```bash
git clone https://github.com/Swir/IPTV-checker.git
cd IPTV-checker
pip install aiohttp PyQt5
```

English:

```bash
python "checker english.py"
```

Polish:

```bash
python checker.py
```
